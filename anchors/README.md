# Anchor patches

768 image patches (256 x 256 pixels, 10x magnification) define the anchor coordinates of OnePrior. `images/000.png` to `images/767.png` are in the order of the coordinate dimensions: dimension *k* of an anchor coordinate is the cosine similarity to the feature of image *k*. Do not reorder or rename them.

| Source | Index | Patches | In this repository |
|---|---|---|---|
| TCGA | 000 to 255 | 256 | yes |
| HISTAI | 256 to 511 | 256 | no, rebuilt from the original slides |
| SPIDER | 512 to 767 | 256 | no, rebuilt from the original patches |

HISTAI and SPIDER are distributed by their authors through an access request on Hugging Face, so their patches are not redistributed here. `anchors.csv` records exactly where every patch comes from, and `build_anchors.py` rebuilds the missing 512 patches from your own copy of the two datasets and checks every patch against a checksum.

## Rebuilding the HISTAI and SPIDER patches

1. Request access to the [HISTAI](https://huggingface.co/histai) datasets and the four SPIDER datasets on Hugging Face.
2. Download the files that are needed. This prints one `hf download` command per dataset: 128 HISTAI slides (about 28 GB) and the four SPIDER archives.

   ```
   python anchors/build_anchors.py --print-downloads
   ```

3. Extract each SPIDER archive as described on its dataset card, so that you have one folder of `patch_*.png` files per organ.
4. Build and verify. The HISTAI crops are read with [TRIDENT](https://github.com/mahmoodlab/TRIDENT), which must be installed.

   ```
   python anchors/build_anchors.py --histai-root histai \
     --spider breast=<folder> colorectal=<folder> skin=<folder> thorax=<folder>
   ```

The script writes the missing images to `images/` and ends with a line such as `built 512, present 768 of 768, checksum mismatches 0`. `--histai-root` is the folder that holds one sub-folder per HISTAI dataset in the layout of Hugging Face (`<dataset>/<case>/<slide>.tiff`). Either source can be built on its own; running the script without arguments only verifies what is present.

How the patches are made:

- **HISTAI**: a 512 x 512 region at the highest resolution of the slide, at the position in `anchors.csv`, read as 20x and resized to 256 x 256 (10x).
- **SPIDER**: the central SPIDER patch and its eight neighbours (224 pixels each, 20x) are joined into a 672 x 672 image; the central 512 x 512 region is resized to 256 x 256 with Lanczos resampling.

## `anchors.csv`

| Column | Meaning |
|---|---|
| `index` | coordinate dimension |
| `file` | image file |
| `source` | TCGA, HISTAI or SPIDER |
| `dataset` | TCGA project, HISTAI dataset or SPIDER organ dataset |
| `slide`, `slide_file` | TCGA slide barcode and file name, HISTAI case and slide file, or SPIDER slide |
| `x_level0`, `y_level0`, `patch_size_level0`, `level0_magnification` | position and size of the patch at the highest resolution of the slide, and the magnification that resolution was read as (TCGA and HISTAI) |
| `spider_grid` | the nine SPIDER patches that are joined, row by row; the fifth is the central patch |
| `selection` | `important` = the patch the pretraining teachers attended most on that slide, `ordinary` = a patch from the middle of their attention ranking, `class-balanced` = SPIDER patches spread over its classes |
| `class` | diagnosis class of the slide (TCGA, HISTAI) or patch label (SPIDER) |
| `sha256` | checksum of the RGB pixels of the patch |

## Code

`coordinates.py` encodes the 768 patches with a patch encoder (`encode_anchors`) and turns slide features into anchor coordinates (`anchor_coordinates`). `encode_anchors` stops with an error while patches are missing.
